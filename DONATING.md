# Donating

This plugin is free, and it stays free. I built it during my own job search, in the hours
between applications, and I am sharing it because the hardest part of a search is not finding
postings, it is turning them into finished applications without losing your mind.

If it helped you, and only if you are in a position to, a donation lets me keep maintaining it
(ATS platforms change, the scripts need care) and helps the next person who downloads it.

- GitHub Sponsors: https://github.com/sponsors/chrispt
- Prefer a one-off? Use the "one-time" option on the same page.

Suggested amounts, for people who like a number: $10 if it saved you an evening, $25 if it got
an application out that you would not otherwise have sent, whatever you like if it got you an
interview. None of this is required.

A note on what a donation is not: it is not support, a licence, or a promise of features. If
you cannot donate, use the tool, land the job, and tell someone else about it. That is worth
just as much.

Improvements are welcome too, especially ATS learnings for platforms not yet covered. Open an
issue or a pull request at https://github.com/chrispt/job-hunt-autopilot, and scrub
anything personal (names, ids, addresses) first.
